# 脱敏样本生成演示（mask）

用人工构造的多文件解码记录演示 `copybook mask` 的全部行为。所有数据都是
编造的，不含任何真实客户信息；`demo_key.txt` 只是演示密钥，真实部署必须
从自己的环境变量或密钥文件提供映射密钥。

```bash
python3 examples/mask/run_scenarios.py
```

运行器会：

1. 用 `build_data.py` 在 `run/` 下生成三个输入文件（账号主表
   `accounts.jsonl`、交易明细 `txns.jsonl`、关联持有人表
   `related.jsonl`，均为 `decode` 的 `write_jsonl` 产出的形状）；
2. 以真实 CLI（子进程）跑主场景，把交付的每条记录**逐字段**对照
   `expected_results.py` 里的手工期望；
3. 打乱输入文件次序、把分块大小改成 1 再跑一遍，要求全部输出文件
   逐字节一致；
4. 逐个跑失败场景，断言退出码为 2、stderr 含对应原因、且不留下
   输出目录。

## 主场景演示点

| 演示点 | 数据 |
|---|---|
| 同一账号跨文件稳定替换 | `1000002345` 出现在三个文件共 5 处，全部得到同一假值 |
| 不同账号不碰撞 | 5 个不同账号映射到 5 个不同假值（冲突检查 passed） |
| 姓名不泄漏原文 | `ZHANG WEI` → 合成值，输出中搜不到任何原文片段 |
| 空值与缺字段分别处理 | 第 3 行 `CUST-NAME: null` 保留为 null；第 4 行整个字段缺失，保持缺失，两者分别计数 |
| 策略拒绝 | 第 5 行 `ALT-ACCT: null` 且策略 `on_null=reject` → 该记录被拒并给出可追踪原因 |
| 金额区间化 | `12345.67` → `10000.00-100000.00`，`999.99` → `<1000.00` |
| 金额确定性偏移 | `TXN-AMOUNT` 按 ±5% 内 HMAC 抖动，小数位保持两位 |
| 日期偏移后仍可连接 | `OPEN-DATE`/`TXN-DATE` 同组 `bizdate`，同一原日期在各文件偏移一致，账号假值仍可连接同一主体 |
| 日期区间泛化 | `HOLDER-SINCE` → `2024-01`（月粒度） |
| 未列入策略的字段 | `BRANCH-CODE` 原样保留 |

## 失败场景

* `policy_path_never_matched` — 策略指向任何记录都不存在的路径；
* `policy_type_mismatch` — 对非十进制文本字段施加金额偏移；
* `wrong_key` — 提供的密钥与策略声明的 `key_fingerprint` 不符；
* `corrupt_input` — 输入 JSONL 中有损坏行；
* `existing_output` — 输出目录已存在（目录内容保持原样）。

## 期望值是怎么来的

计数、拒绝原因、区间标签、空值/缺字段行为、连接关系都是手工从场景数据
和策略逐条写出的字面量。HMAC 决定的脱敏值（假账号、合成姓名、偏移后的
金额与日期）无法纸笔手算，`expected_results.py` 里有一份**独立的参考
实现**——只依据文档化的算法规范（域分隔符、消息布局、计数器模式密钥流、
拒绝采样、精确有理数舍入、合成姓名池）用标准库重写，不 import
`copybook.mask`；运行器断言真实引擎输出与该参考逐字段一致。实现与规范
一旦分叉，对照即失败。
